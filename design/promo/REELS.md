# 릴스 촬영 가이드 (참고: 휴대폰으로 모니터를 찍은 개발자 릴스)

참고 릴스는 모니터를 휴대폰으로 찍은 영상이에요. 왼쪽에 코드가 있고 오른쪽에 아이폰 화면이 떠 있으며, 경기장 → 구역 → 좌석 → "이 자리에서 보이는 시야" 순서로 넘어가요.
무비메이트는 극장 → 관 → 좌석 → 3D 시야로 흐름이 같아서 구도만 따라 하면 돼요.

## 1. 데모 띄우기

```bash
npx next start -p 3100
```

처음 한 번만, 프로젝트 밖에 Playwright를 깔아요(프로젝트 의존성은 그대로 둬요. 브라우저는 설치된 Chrome을 써요).

```bash
mkdir -p ~/.cache/movie-mate-pw && npm i --prefix ~/.cache/movie-mate-pw playwright@1.58
```

```bash
PLAYWRIGHT_FROM=~/.cache/movie-mate-pw node design/promo/reels-demo.mjs
```

찍을 준비가 되면 Claude에게 "데모 띄워줘"라고 해도 돼요.

- 휴대폰 크기(393×852) Chrome 창이 뜨고, 아래 흐름을 사람 속도로 계속 되풀이해요. 한 바퀴는 약 30초예요.
  1. 홈 → CGV → 서울 → CGV 용산아이파크몰 → 이 극장으로 (0~7초)
  2. IMAX관 → 이 관 좌석 보기 (7~11초)
  3. N열 가운데 자리 누르기 → 미리보기 → 이 자리에서 보기 (11~16초)
  4. 3D 시야가 열림 → 손가락으로 좌우 둘러보기 (16~23초)
  5. 키 버튼 → 120cm로 내리면 앞사람 머리가 스크린을 가리고, 200cm로 올리면 트임 (23~30초)
- 커서는 시뮬레이터처럼 화살표로 보이고, 누를 때 물결이 퍼져요.
- 끄려면 터미널에서 Ctrl+C를 누르세요.

## 2. 화면 구도 (모니터)

- **왼쪽 2/3:** 에디터. `src/features/viewer/Scene.tsx`처럼 3D를 그리는 코드나 Claude Code 터미널을 띄워요. 참고 릴스의 "만드는 사람" 느낌이 여기서 나와요.
- **오른쪽 1/3:** 데모 창. 화면 세로 가운데에 두고, 위아래로 여백을 조금 남겨요.
- **macOS 다크 모드**로 하고 바탕화면은 어둡게 두세요. 3D 화면이 어두워서 밝은 바탕이면 휴대폰이 노출을 낮춰 버려요.
- **집중 모드(방해 금지)를 켜세요.** 메신저나 메일 알림, 독의 개인 앱 배지가 찍히지 않게 하고, 에디터에 `.env` 같은 파일이 열려 있지 않은지 확인하세요.

## 3. 휴대폰 설정

| 항목 | 추천 |
|---|---|
| 해상도·프레임 | 4K 30fps (끊김 없이 부드럽게 하려면 4K 60fps) |
| 렌즈 | 1× 기본 렌즈. 초광각은 모니터가 휘어 보여요 |
| 초점·노출 | 데모 창을 길게 눌러 AE/AF 잠금 → 노출을 -0.7 정도 내리기 (스크린 영상이 하얗게 날아가지 않게) |
| 화면 밝기 | 모니터 밝기 60~70%, 방 불은 끄거나 어둡게 |
| 모아레(물결무늬) | 모니터와 정면이 아니라 10~15° 비스듬히, 40~60cm 떨어져서. 물결이 보이면 조금 물러나거나 각도를 바꾸세요 |
| 세로 | 휴대폰을 세로로 들고 찍어요(9:16) |

## 4. 카메라 움직임 (참고 릴스처럼 손으로)

1. **0~3초:** 에디터와 데모 창이 같이 보이게 넓게 시작해요. 손에 든 느낌으로 살짝 흔들려도 괜찮아요.
2. **좌석을 누를 때(11초쯤):** 데모 창 쪽으로 천천히 다가가요. 휴대폰이 데모 창을 화면 2/3쯤 채울 때까지요.
3. **3D 시야가 열릴 때(16초쯤):** 거기서 멈추고 둘러보는 장면을 그대로 담아요. 가장 중요한 장면이에요.
4. **키를 바꿀 때(23초쯤):** 조금 더 다가가 머리가 비키는 장면을 담고 끝내요.

한 번에 잘 안 되면 데모가 계속 되풀이되니 몇 번 이어서 찍고 가장 좋은 바퀴를 고르세요.

## 5. 편집 (15~20초)

- **빠르게(1.5~2배):** 1~2번 (극장·관 고르기)
- **그대로(1배):** 3~5번 (좌석 → 3D 시야 → 키)
- **끝:** 마지막 0.5초는 키가 200cm로 올라가 트인 화면에서 끊기. 로고 장면이 필요하면 `design/promo/out/film-15.mp4`의 마지막 3초(로고)를 붙여도 돼요.
- **글자:** 영상 위 글자는 쓰지 않고, 캡션에 한 줄로 쓰세요.
- **음악:** 미니멀한 일렉트로닉이나 로파이, 100~120 BPM, 보컬 없는 곡. 인스타 음악 검색어로 "lofi", "minimal", "chill beat"를 써 보세요. 3D가 열리는 순간을 박자에 맞추면 좋아요.
