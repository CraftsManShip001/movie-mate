# 릴스 촬영 가이드 (참고: 휴대폰으로 모니터를 찍은 개발자 릴스)

참고 릴스는 모니터를 휴대폰으로 찍은 영상이에요. 왼쪽에 코드, 오른쪽에 아이폰 시뮬레이터가 있고, 흐름은 경기장 → 구역 → 좌석 → "그 자리에서 보이는 경기장" → 결제 완료예요.
무비메이트는 이 흐름을 그대로 옮길 수 있어요.

| 참고 릴스 | 무비메이트 데모 |
|---|---|
| 경기장 3D 지도에서 구역 누르기 | 메가박스 코엑스 시간표에서 영화(라라랜드) → 내일 → 시간 누르기 |
| 좌석 지도에서 자리 누르기 | 좌석표에서 가운데 뒤쪽 빈자리 누르기 → 시야 미리보기 |
| 그 자리에서 본 3D 경기장 | 티켓이 출력된 뒤 그 자리에서 본 3D 스크린 → 손가락으로 둘러보기 |
| "You're in" 결제 완료 | (마지막) 3D 시야. 결제는 각 영화관에서 하니 흉내 내지 않아요 |

## 1. 데모 띄우기

처음 한 번만, 프로젝트 밖에 Playwright를 깔아요(프로젝트 의존성은 그대로 둬요. 브라우저는 설치된 Chrome을 써요).

```bash
mkdir -p ~/.cache/movie-mate-pw && npm i --prefix ~/.cache/movie-mate-pw playwright@1.58
```

```bash
npx next start -p 3100
```

```bash
PLAYWRIGHT_FROM=~/.cache/movie-mate-pw node design/promo/reels-demo.mjs
```

- 휴대폰 크기(393×852) Chrome 창이 뜨고, 위 흐름을 사람 속도로 계속 되풀이해요. 한 바퀴는 약 30초예요.
  1. 0~6초: 시간표 → 라라랜드 → 내일 → 16:15
  2. 6~12초: 좌석표 → 빈자리 → 미리보기
  3. 12~16초: 이 자리에서 보기 → 티켓 출력
  4. 16~30초: 3D 시야 → 좌우로 둘러보기
- 다른 영화로 찍으려면 `MOVIE="영화 제목"`을 앞에 붙이세요. 키 조절이 나오는 CGV IMAX 흐름은 `FLOW=cgv`예요.
- 끄려면 터미널에서 Ctrl+C를 누르세요.
- 찍을 준비가 되면 Claude에게 "데모 띄워줘"라고 해도 돼요.

## 2. 화면 구도 (모니터)

- **왼쪽 2/3:** 에디터. `src/features/viewer/Scene.tsx`(3D를 그리는 코드)나 Claude Code 터미널을 띄워요. 참고 릴스의 "직접 만든 사람" 느낌이 여기서 나와요. 글자 크기를 평소보다 1~2단계 키우면 휴대폰으로 찍어도 코드처럼 보여요.
- **오른쪽 1/3:** 데모 창. 화면 세로 가운데에 두세요.
- **macOS 다크 모드**로 하고 바탕화면은 어둡게 두세요. 3D 화면이 어두워서 밝은 바탕이면 휴대폰이 노출을 낮춰 버려요.
- **집중 모드(방해 금지)를 켜세요.** 메신저나 메일 알림, 독의 개인 앱 배지가 찍히지 않게 하고, `.env` 같은 파일이 열려 있지 않은지 확인하세요.

## 3. 휴대폰 설정

| 항목 | 추천 |
|---|---|
| 해상도·프레임 | 4K 30fps (스크롤까지 매끄럽게 하려면 4K 60fps) |
| 렌즈 | 1× 기본 렌즈. 초광각은 모니터가 휘어 보여요 |
| 초점·노출 | 데모 창을 길게 눌러 AE/AF 잠금 → 노출 -0.7 정도 (스크린 영상이 하얗게 날아가지 않게) |
| 밝기 | 모니터 60~70%, 방 불은 끄거나 어둡게 (참고 릴스처럼 화면만 빛나게) |
| 모아레(물결무늬) | 정면이 아니라 10~15° 비스듬히, 40~60cm 떨어져서. 물결이 보이면 조금 물러나거나 각도를 바꾸세요 |
| 방향 | 세로(9:16) |

## 4. 찍는 법 (한 번에 이어서, 손으로 들고)

참고 릴스는 컷 없이 휴대폰을 든 채로 천천히 움직여요. 그 느낌으로 찍으세요.

1. **시작 (0~3초):** 에디터와 데모 창이 같이 보이게 넓게 잡아요. 살짝 흔들려도 괜찮아요.
2. **좌석을 누를 때 (6초쯤):** 데모 창 쪽으로 천천히 다가가요. 화면의 2/3를 데모 창이 채울 때까지요.
3. **티켓이 나올 때 (12초쯤):** 그대로 멈춰서 티켓이 찍혀 나오는 장면을 담아요.
4. **3D 시야 (16초~):** 조금 더 다가가 둘러보는 장면을 끝까지 담아요. 가장 중요한 장면이에요.

데모가 계속 되풀이되니 몇 바퀴 이어서 찍고 가장 좋은 바퀴를 고르세요.

## 5. 편집 (15~20초)

- **첫 1초:** 3D 시야 장면을 0.8~1초 먼저 보여 주고, 처음 흐름으로 돌아가요. 릴스는 첫 1초에 넘길지 정해져서, 결과를 먼저 보여 주는 편이 끝까지 봐요.
- **빠르게(1.5~2배):** 시간표·영화 고르기
- **그대로(1배):** 좌석 누르기 → 티켓 → 3D 시야
- **끝:** 둘러보다 정면으로 돌아온 순간에 끊어요. 로고 장면이 필요하면 `design/promo/out/reels.mp4`의 마지막 3초를 붙여도 돼요.
- **글자:** 영상 위에는 첫 장면에 한 줄만 넣으세요. 예: "예매 전에, 그 자리에서 보이는 스크린". 나머지는 캡션에 써요.
- **음악:** 미니멀한 일렉트로닉이나 로파이, 100~120 BPM, 보컬 없는 곡. 인스타 음악 검색어로 "lofi", "minimal", "chill beat"를 써 보세요. 티켓이 나오는 순간이나 3D가 열리는 순간을 박자에 맞추면 좋아요.
