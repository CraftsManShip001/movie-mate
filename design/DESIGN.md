# movie mate 디자인 기록

확정일: 2026-11-16 · 캔버스: https://claude.ai/artifact/MFXqAe8UqQStdrV8NJ7F1H

확정본은 `flow-a/FlowA1R2.dc.html`(흐름 5화면 + 티켓 장면)과 `flow-a/FlowA_States.dc.html`(나머지 상태 6화면)이다. 구현할 때는 이 두 파일을 원본으로 본다.

## 흐름 (데스크톱이 기본)

1. **영화관**: CGV · 메가박스 · 롯데시네마 중에서 브랜드를 먼저 고르고, 오른쪽에서 극장을 고른다. 목록 제목은 "시야를 볼 수 있는 극장"이다.
2. **상영 시간**: 관별로 묶어서 보여 준다.
   - 관 줄에는 관 이름 · 포맷·자막 · 화면비 · 좌석 수 · 시야 미리보기 가능 여부를 둔다.
   - 시간 칸에는 시작 시각 · 끝나는 시각 · 남은 좌석을 둔다. 남은 좌석이 40석 미만이면 강조색으로 표시한다.
   - 맨 위에 날짜 7일을 둔다.
3. **좌석**: 왼쪽에 좌석표, 오른쪽에 고른 자리 · 작은 시야 · 수치를 둔다.
4. **티켓**: 버튼이 없는 지나가는 장면이다(약 3.4초). 순서는 다음과 같다.
   - 키오스크 출력구에서 티켓이 입장권 면을 보이며 출력된다.
   - 툭 떨어진다.
   - 두 장으로 나뉜다. 왼쪽 장은 포스터 면으로 뒤집히고, 오른쪽 장은 입장권 면 그대로다.
   - 자동으로 5번으로 넘어간다.
5. **시야**: 3D 시야가 화면 전체를 채운다. 배치는 다음과 같다.
   - 오른쪽 위: "CGV에서 예매하기"
   - 오른쪽 아래: 미니 티켓과 작은 좌석표. "좌석·티켓 숨기기/보기"로 켜고 끈다.
   - 앞사람 켜기/끄기 버튼
   - "키 166cm" 버튼: 누르면 위로 슬라이더(120~200cm)가 열리고, 바꾼 값은 저장되어 3번 작은 시야에도 반영된다. 기본값이 아니면 "평균 키로" 버튼이 나온다.
   - 왼쪽 아래: 수치

## 화면 틀 (토스·당근 기준으로 정한 것)

- **헤더:** 단계 막대를 쓰지 않는다. 헤더는 "‹ 뒤로 + 제목" 하나이고 높이는 72px이다.
- **하단 고정 줄:** 1~3번 화면에 둔다. 왼쪽에 지금까지 고른 것, 오른쪽에 다음 행동 버튼 하나(320×56)를 놓는다.
- **용어:**
  - "발권"이라고 쓰지 않는다. 실제 예매로 오해할 수 있어서다.
  - 3번 버튼은 "이 자리에서 보기"다.
  - 실제 예매는 "CGV에서 예매하기"로 각 극장 사이트에 맡긴다.
- **문구:** 해요체로 짧게 쓴다. 내부 용어(도면 등)는 쓰지 않는다.

## 티켓 (2026-11-20 확정 · B-1 블랙 에디션)

확정 보드는 `ticket/TicketP1.dc.html`의 B-1 칸이다. 코드는 `src/features/ticket/Ticket.tsx`.

- **모양:** 250×520. 위아래에 반원 홈(반지름 6, 간격 26)을 파고, 네 모서리는 오목하게(반지름 14) 깎는다.
- **앞면:** 포스터만 담는다.
  - 포스터가 앞면 전체를 채운다. 포스터는 2:3이라 양옆이 약 14%씩 잘린다.
  - 상영 일시, 극장, 좌석 같은 글자는 넣지 않는다. 앞면에 남는 것은 외곽선(홈)과 포스터뿐이다.
  - 5번 미니 티켓도 이 앞면을 줄인 것이라 포스터만 보인다.
  - 시간표의 포스터는 목록용 썸네일이라 앞면에는 큰 판을 쓴다(`ticketPosterUrl`). 메가박스는 원본 448×640, 롯데시네마는 `_504_1` 600×860. 불러오지 못하면 목록용 포스터로 바꾼다.
- **뒷면:** 무광 검정 종이에 은색 글자. 영화관(체인·지점), 상영관, 좌석, 날짜, 시각은 모두 뒷면에 둔다. 위에서부터 이렇게 놓는다.
  - "MOVIE MATE", No.
  - 제목(Hahmlet 30px)과 영문 한 줄
  - 왼쪽 SEAT, 오른쪽 속이 빈 큰 좌석 번호(Bebas Neue 104px, 1.4px 선). 번호가 5자면 84px, 6자 이상이면 68px
  - 얇은 선 사이에 THEATER / SCREEN / DATE / TIME / VIEW / DISTANCE 줄. 값이 길면 말줄임
  - SEE BEFORE YOU SIT, 바코드
  - 4·5번 어두운 바탕에서 윤곽이 묻히지 않도록 안쪽 테두리 1px(`#38383E`)를 둔다. 시안에는 없던 것이다.
- **약점:** 제목 글자가 포스터 양 끝까지 넓게 놓인 포스터(예: 폭설)는 앞면에서 제목 양 끝이 잘린다.

## 로고 (2026-11-20 확정 · E-2 + 벨벳 버건디)

- **모양:** 가로 티켓 반쪽(E-2). 세로 절취선(x=64, 틈 4) 위아래에 반원 홈이 있다. 왼쪽이 본권, 오른쪽이 꼭지다. 글자는 넣지 않는다.
- **색:** 버건디 `#A3192E`는 로고에만 쓴다(`--color-brand`). 화면 강조색(`accent #E5432F`)과는 따로 둔다.

| 바탕 | 본권 | 꼭지 |
|---|---|---|
| 흰색 | 버건디 | ink `#141414` |
| 버건디(앱 아이콘) | 흰색 | 연분홍 `#DAA3AB` |
| 검정·stage | 버건디 | 흰색 |

- **크기:** 48px 이상은 큰 판, 32px 이하는 작은 판을 쓴다. 16px 작은 판은 16칸 격자에 맞춰 따로 그렸고, 꼭지까지 버건디 한 색이다(검은 꼭지를 두면 비디오 카메라처럼 보였다).
- **아이콘 타일:** 모서리 반지름 22.5%, 로고는 타일의 64%.
- **코드:** `src/features/brand/Logo.tsx`(큰 판), `src/app/icon.svg`·`favicon.ico`(16px 작은 판), `src/app/apple-icon.png`(버건디 타일 180px). 1번 화면 헤더 왼쪽에 28px로 둔다.
- **약점:** 어두운 바탕(다크 브라우저 탭, 시야 화면)에서는 버건디가 가라앉는다.
- **보드:** `logo/*.png`, 생성기 `tools/gen_logo*.py`(gen_logo_small → gen_logo_e2 → gen_logo_e).

## 나머지 상태 (FlowA_States)

- 고른 브랜드에 극장이 없을 때
- 고른 날 상영이 없을 때
- 시야 미리보기가 없는 관을 골랐을 때: 주요 버튼을 끄고 "CGV에서 예매하기"를 둔다.
- 좌석을 불러오는 중
- 시야 화면에서 좌석·티켓을 숨겼을 때
- 시야를 불러오지 못했을 때: "다시 시도" 버튼을 둔다.

## 생성기

`tools/gen*.py`는 캔버스 보드를 만드는 스크립트다. 나중 단계의 파일이 앞 단계 파일의 부품을 가져다 쓴다(gen12 → gen11 → gen10 → … → gen2).

```bash
python3 design/tools/gen12.py <캔버스 폴더>
```

캔버스 폴더 아래 `project/`에 보드 파일과 `canvas.json`이 있어야 한다. 실제 포스터 이미지는 캔버스 자산 `/_blob/7311fb27350ae63e3cd0964fc61338d6`이고, 원본 파일은 `assets/odyssey-tmdb.jpg`다.
