# movie mate 디자인 기록

확정일: 2026-11-16 · 캔버스: https://claude.ai/artifact/MFXqAe8UqQStdrV8NJ7F1H

확정본은 `flow-a/FlowA1R2.dc.html`(흐름 5화면 + 티켓 장면)과 `flow-a/FlowA_States.dc.html`(나머지 상태 6화면)이다. 구현할 때는 이 두 파일을 원본으로 본다.

## 흐름 (데스크톱이 기본)

1. **영화관**: CGV · 메가박스 · 롯데시네마 중에서 브랜드를 먼저 고르고, 오른쪽에서 극장을 고른다. 목록 제목은 "시야를 볼 수 있는 극장"이다.
2. **상영 시간**: 관별로 묶어서 보여 준다.
   - 관 줄에는 관 이름 · 포맷·자막 · 화면비 · 좌석 수 · 시야 미리보기 가능 여부를 둔다.
   - 시간 칸에는 시작 시각 · 끝나는 시각 · 남은 좌석을 둔다. 남은 좌석이 40석 미만이면 강조색으로 표시한다.
   - 맨 위에 날짜 7일을 둔다.
3. **좌석**: 왼쪽에 좌석표, 오른쪽에 고른 자리 · 작은 시야 · 수치를 둔다.
4. **티켓**: 버튼이 없는 지나가는 장면이다(약 3.4초). 순서는 다음과 같다.
   - 키오스크 출력구에서 티켓이 입장권 면을 보이며 출력된다.
   - 툭 떨어진다.
   - 두 장으로 나뉜다. 왼쪽 장은 포스터 면으로 뒤집히고, 오른쪽 장은 입장권 면 그대로다.
   - 자동으로 5번으로 넘어간다.
5. **시야**: 3D 시야가 화면 전체를 채운다. 배치는 다음과 같다.
   - 오른쪽 위: "CGV에서 예매하기"
   - 오른쪽 아래: 미니 티켓과 작은 좌석표. "좌석·티켓 숨기기/보기"로 켜고 끈다.
   - 앞사람 켜기/끄기 버튼
   - 왼쪽 아래: 수치

## 화면 틀 (토스·당근 기준으로 정한 것)

- **헤더:** 단계 막대를 쓰지 않는다. 헤더는 "‹ 뒤로 + 제목" 하나이고 높이는 72px이다.
- **하단 고정 줄:** 1~3번 화면에 둔다. 왼쪽에 지금까지 고른 것, 오른쪽에 다음 행동 버튼 하나(320×56)를 놓는다.
- **용어:**
  - "발권"이라고 쓰지 않는다. 실제 예매로 오해할 수 있어서다.
  - 3번 버튼은 "이 자리에서 보기"다.
  - 실제 예매는 "CGV에서 예매하기"로 각 극장 사이트에 맡긴다.
- **문구:** 해요체로 짧게 쓴다. 내부 용어(도면 등)는 쓰지 않는다.

## 티켓 (오리지널 티켓형)

- **모양:** 250×520. 위아래에 반원 홈(반지름 6, 간격 26)을 파고, 네 모서리는 오목하게(반지름 14) 깎는다.
- **앞면:**
  - 위쪽은 포스터(2:3)다.
  - 아래 띠에는 상영 일시와 극장 두 줄만 넣는다. 제목, 영문, 좌석 번호는 넣지 않는다(포스터에 이미 제목이 있다).
- **뒷면:** 위에서부터 이렇게 놓는다.
  - "MOVIE MATE ORIGINAL", No.
  - 제목(Hahmlet)과 영문 한 줄
  - 굵은 선 사이에 SEAT와 큰 좌석 번호
  - THEATER / SCREEN / DATE / TIME / VIEW / DISTANCE 줄
  - 바코드

## 나머지 상태 (FlowA_States)

- 고른 브랜드에 극장이 없을 때
- 고른 날 상영이 없을 때
- 시야 미리보기가 없는 관을 골랐을 때: 주요 버튼을 끄고 "CGV에서 예매하기"를 둔다.
- 좌석을 불러오는 중
- 시야 화면에서 좌석·티켓을 숨겼을 때
- 시야를 불러오지 못했을 때: "다시 시도" 버튼을 둔다.

## 아직 정하지 않은 것

- 시야 수치(시야각·올려보기)를 쉬운 말로 바꿀지
- 휴대폰 화면
- 다크 모드 값
- 실제 상영 시간표·남은 좌석 데이터를 어디서 받을지
- 포스터 사용 권리 (TMDB 약관과 출처 표기)

## 생성기

`tools/gen*.py`는 캔버스 보드를 만드는 스크립트다. 나중 단계의 파일이 앞 단계 파일의 부품을 가져다 쓴다(gen12 → gen11 → gen10 → … → gen2).

```bash
python3 design/tools/gen12.py <캔버스 폴더>
```

캔버스 폴더 아래 `project/`에 보드 파일과 `canvas.json`이 있어야 한다. 실제 포스터 이미지는 캔버스 자산 `/_blob/7311fb27350ae63e3cd0964fc61338d6`이고, 원본 파일은 `assets/odyssey-tmdb.jpg`다.
